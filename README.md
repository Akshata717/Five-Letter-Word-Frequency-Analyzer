# Five-Letter-Word-Frequency-Analyzer
A Python program that processes a text file to analyze five-letter words by cleaning punctuation, normalizing case, and identifying word frequencies.

## Overview
This project reads a text file, removes punctuation, converts all words to lowercase, and extracts all five-letter words. It then counts how often each word appears and reports the most frequent five-letter word along with the total number of five-letter words found.

## Features
- Reads and processes text files using Python file I/O
- Removes punctuation using a hash table (dictionary) lookup
- Normalizes text by converting all characters to lowercase
- Extracts and counts five-letter words
- Identifies the most frequently occurring five-letter word

## Example Output, Reading Alice in Wonderland

The five-letter word that appears the most is alice, it appears 398 times.
In total, there are 3341 five-letter words.
